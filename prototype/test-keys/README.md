# Test Keypairs for BLE Relay Development

⚠️ **WARNING**: These are TEST-ONLY keys. NEVER use in production.

## Files
- android.privkey.hex — Android's Noise IK private key (32 bytes)
- android.pubkey.hex — Android's Noise IK public key (33 bytes compressed)
- daemon.privkey.hex — fips daemon's private key (32 bytes)
- daemon.npub.txt — fips daemon's public key in npub format

## Usage
These keys are used for local development testing of the BLE↔TCP relay bridge.
